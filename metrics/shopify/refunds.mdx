## How it's calculated

```text
value = the positive refund total, preferring totalRefundedSet and otherwise summing refund transaction amounts. Period value = SUM(value).
```

### Built from

- `Refund.totalRefundedSet.shopMoney.amount`
- `Refund.transactions[].amountSet.shopMoney.amount`

## Known caveats

- Use Shopify returns for the ShopifyQL daily-sales breakdown.
