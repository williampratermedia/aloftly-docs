## How it's calculated

```text
value = 1 for order creation and -1 for cancellation. Period value = SUM(value).
```

### Built from

- `Order.id`
- `Order.createdAt`
- `Order.cancelledAt`

## Known caveats

- Distinct from ShopifyQL sales-report order count.

## Where this appears

- Stores page order count
- KPI fallback when Shopify analytics is unavailable
