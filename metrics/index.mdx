This library is the canonical contract for metrics displayed by Aloftly. Each page explains what the metric means, how it is calculated, where it comes from, its grain and filters, and the conditions under which it can be unavailable.

These definitions are generated from the same certified semantic catalog that Aloftly's query and AI layers use, so a metric means the same thing everywhere it appears.

## Shared query rules

- Tenant identity is resolved server-side. Browser-supplied organization identity is never trusted.
- Date filters use half-open windows: values at the start are included and values at the end are excluded.
- A missing value is not rewritten as zero. Ratios return unavailable when their required denominator or coverage is missing.
- Shopify is the primary authority for commerce and store conversion. GA4 is the primary authority for web traffic and page analytics.
- Aloftly does not currently perform foreign-exchange conversion. Cross-store currency totals require the stores to share a currency.
- No metric should claim paid-only or bot-excluded behavior unless its page explicitly names that filter.
