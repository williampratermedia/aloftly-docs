## How it's calculated

```sql
100 * (previous_stage - current_stage) / NULLIF(previous_stage, 0)
```

### Built from

- `ShopifyQL funnel counts`

## Known caveats

- Returns zero when the previous stage is zero; it does not infer missing stages.
