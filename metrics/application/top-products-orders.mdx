## How it's calculated

```sql
COUNT(DISTINCT COALESCE(NULLIF(dimensions->>'orderToken', ''), NULLIF(dimensions->>'orderId', '')))
```

### Built from

- `Order identity token`

## Known caveats

- An order containing multiple lines for the grouped product still counts once.
